# Car Chaser skills

The two skills for the [Car Chaser Grok Bot template](https://x.ai/bot/_xHffm8tWVvtVic-aJmwa):

- [`car-chaser-getting-started`](skills/car-chaser-getting-started/SKILL.md): first chat, turns your search into saved rules and shows real matches.
- [`photo-filter-car-watch`](skills/photo-filter-car-watch/SKILL.md): every search and daily check.

Grok Bot template imports currently drop skills, so Car Chaser installs these itself on its first message from a pinned commit of this repo.
